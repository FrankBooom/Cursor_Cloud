## 1. 产品概述

### 1.1 产品定位

一款面向 **日常口语** 的英语学习应用，以 **「输入 → 记忆 → 输出 → 反馈」** 为闭环。

用户通过每日推送发现**真实生活场景中的地道表达**，整理为个人背诵材料，用记忆卡片记住「能直接说出口」的句子和短语，并通过随机口语题在模拟对话中开口练习。

**不做：** 考试刷题、学术写作、商务邮件、语法题海。  
**专注：** 旅行、社交、购物、点餐、闲聊等高频生活场景。

### 1.2 产品愿景

让学习者用最少操作完成：**每天学几句地道口语、记住能用的表达、敢开口说出来**。

### 1.3 核心价值

| 价值 | 说明 |
|------|------|
| 低门槛开始 | 推送即学，一键加入背诵 |
| 场景化学习 | 按生活场景组织内容，学了就能用 |
| 科学记忆 | 间隔重复，减少遗忘 |
| 真实输出 | 模拟真实对话提问 + 录音，练「敢说」 |
| 个人定制 | 用户自主整理，形成专属口语句库 |

### 1.4 目标用户（MVP 聚焦）

**主用户：日常口语学习者**

| 维度 | 描述 |
|------|------|
| 年龄 | 18–40 岁 |
| 典型场景 | 出国旅行、看英文内容、与外国朋友交流、自我提升 |
| 学习场景 | 通勤、睡前、碎片时间（单次 5–15 分钟） |
| 核心痛点 | 背了很多单词但不会组句；想说但不敢开口；不知道日常对话怎么说 |
| 英语基础 | 初级–中级（CEFR A2–B1），能读懂简单句子但口语流利度不足 |
| 学习动机 | 「能用起来」> 「考高分」 |

**典型用户画像：**

- **小林，26 岁，上班族**：计划去日本旅行，想学会点餐、问路、购物时的常用口语
- **阿杰，22 岁，大学生**：想和外教/网友聊天，但只会 Yes/No，需要积累闲聊表达
- **王女士，35 岁，家长**：孩子学英文，自己也想补日常口语，方便日常交流

**明确不服务（MVP 阶段）：** 考研/雅思/托福备考、商务谈判、学术英语

### 1.5 日常口语内容原则

所有功能设计须符合以下原则：

| 原则 | 说明 | 反例（不做） |
|------|------|--------------|
| **句子优先** | 优先学完整口语句和搭配，而非孤立单词 | 单独背 abandon、abstract |
| **地道实用** | 内容贴近真实对话，含口语缩略、常用短语 | 过于书面：I would like to inquire... |
| **场景驱动** | 按生活场景分类，用户知道「什么时候用」 | 纯词频排序、无场景 |
| **可说出** | 每条推送/卡片都应能直接用于开口 | 长难语法讲解 |
| **低压力** | 口语练习重「敢开口」，MVP 不强调打分 | 一开口就红字纠错 |

## 2. 产品目标与成功指标

### 2.1 业务目标（上线后 3 个月）

- 次日留存 ≥ 35%
- 7 日留存 ≥ 20%
- 人均每周学习天数 ≥ 3 天
- 口语练习完成率（开始录音并完成保存）≥ 60%
- 用户自评「敢开口」比例（问卷）≥ 70%

### 2.2 核心行为指标

| 指标 | 定义 | MVP 目标 |
|------|------|----------|
| DAU 学习完成率 | 当日完成「卡片复习 OR 口语一题」的用户占比 | ≥ 50% |
| 卡片掌握率 | 标记为「已掌握」/ 总复习卡片 | 逐周提升 |
| 推送转化率 | 推送内容被「加入背诵」的比例 | ≥ 15% |
| 连续打卡 | 连续学习 ≥ 7 天的用户占比 | ≥ 10% |

## 5. 功能需求详述

### 5.1 模块一：记忆卡片（Flashcards）

#### 5.1.1 功能描述

用户以卡片形式背诵 **口语表达、常用句型、场景对话块**；系统按间隔重复算法安排复习。

**日常口语导向：** 卡片默认以「句子/短语」为主，而非孤立单词。每张卡片应能回答「这句话在什么场景下说」。

#### 5.1.2 用户故事

| ID | 用户故事 | 优先级 |
|----|----------|--------|
| F-01 | 作为用户，我想手动创建一张卡片（正面/背面），以便记录我想背的内容 | P0 |
| F-02 | 作为用户，我想从推送/Inbox 一键生成卡片，以便减少录入成本 | P0 |
| F-03 | 作为用户，我想进入「今日复习」按系统推荐顺序背卡片 | P0 |
| F-04 | 作为用户，我想对每张卡片标记「认识 / 模糊 / 不认识」，以便系统安排下次复习 | P0 |
| F-05 | 作为用户，我想切换复习模式（看英想中 / 看中想英 / 听读跟读） | P1 |
| F-06 | 作为用户，我想把卡片按生活场景分组（如「餐厅」「旅行」「闲聊」） | P0 |
| F-07 | 作为用户，我想看到卡片的学习状态（新卡 / 学习中 / 已掌握） | P0 |
| F-08 | 作为用户，我想在卡片上看到场景标签和使用提示（什么时候说） | P1 |

#### 5.1.3 卡片数据结构

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 唯一标识 |
| deck_id | string | 是 | 所属牌组 |
| front | string | 是 | 正面（如英文单词/句子） |
| back | string | 是 | 背面（如中文释义） |
| card_type | enum | 是 | phrase / sentence / dialogue_chunk |
| scene | string | 否 | 场景标签（如 restaurant / travel / small_talk） |
| usage_hint | string | 否 | 使用场景提示（中文，如「点餐时要一份套餐」） |
| audio_url | string | 否 | 发音音频 |
| example | string | 否 | 例句 |
| tags | string[] | 否 | 标签 |
| source | enum | 是 | manual / push / import |
| ease_factor | number | 是 | 间隔重复参数 |
| interval_days | number | 是 | 下次复习间隔 |
| next_review_at | datetime | 是 | 下次复习时间 |
| status | enum | 是 | new / learning / mastered / relearning |

#### 5.1.4 复习流程

```
进入「今日复习」
    → 展示卡片正面
    → 用户点击「显示答案」
    → 用户选择：认识 / 模糊 / 不认识
    → 系统更新间隔与 next_review_at
    → 下一张，直至今日队列完成
    → 展示本次统计（复习数、正确率、明日待复习数）
```

#### 5.1.5 间隔重复规则（MVP 简化版）

| 用户选择 | 间隔变化 |
|----------|----------|
| 不认识 | 重置为 10 分钟后（当日可再次出现）或 1 天 |
| 模糊 | 当前间隔 × 1.2，最短 1 天 |
| 认识 | 当前间隔 × 2.5，按 1→3→7→14→30 天上调 |

#### 5.1.7 MVP 默认牌组（日常口语场景）

| 牌组 | 示例内容 | 优先级 |
|------|----------|--------|
| 日常寒暄 | How's it going? / Not bad, thanks. | P0 |
| 旅行出行 | Where's the nearest subway? / Could you take a photo for us? | P0 |
| 餐厅点餐 | I'd like the set menu. / Can I get this to go? | P0 |
| 购物消费 | Do you have this in a smaller size? / I'm just looking, thanks. | P1 |
| 表达感受 | I'm exhausted. / That sounds awesome! | P1 |
| 闲聊拓展 | What do you do for fun? / Have you seen any good shows lately? | P1 |

**MVP 不包含：** 商务会议、邮件写作、学术讨论

#### 5.1.8 验收标准

- [ ] 用户可创建、编辑、删除卡片
- [ ] 今日复习队列仅包含 `next_review_at <= 今日` 的卡片
- [ ] 每次复习后 `next_review_at` 正确更新
- [ ] 复习结束后展示正确率与连续天数
- [ ] 单张卡片复习响应时间 < 200ms（本地缓存命中时）
- [ ] 默认牌组均为日常口语场景，无考试/商务类

### 5.2 模块二：随机口语题 + 录音回答（Speaking Practice）

#### 5.2.1 功能描述

系统随机生成 **生活场景下的英语对话问题**，用户录音回答，可回放；MVP 提供转写文本与参考回答，V2 提供 AI 反馈。

**日常口语导向：** 题目像朋友闲聊，而非面试/考试；限时 30–90 秒为主，降低开口压力。

#### 5.2.2 用户故事

| ID | 用户故事 | 优先级 |
|----|----------|--------|
| S-01 | 作为用户，我想随机获得一道英语问题，以便练习口语 | P0 |
| S-02 | 作为用户，我想按生活场景筛选问题（旅行/餐厅/闲聊等） | P0 |
| S-03 | 作为用户，我想录音回答并限时（默认 60 秒） | P0 |
| S-04 | 作为用户，我想回放录音对比自己的回答 | P0 |
| S-05 | 作为用户，我想重录覆盖上一次回答 | P0 |
| S-06 | 作为用户，我想看到我的回答被转成文字（ASR） | P1 |
| S-07 | 作为用户，我想看到参考回答（地道口语示范），而非语法纠错 | P1 |
| S-08 | 作为用户，我想练习「今日推送」里刚学过的句子 | P0 |
| S-09 | 作为用户，我想做「情景模拟」（如：你在餐厅，服务员问 What can I get for you?） | P1 |

#### 5.2.3 问题类型（MVP — 日常口语）

| 类型 | 示例 | 场景 | 难度 |
|------|------|------|------|
| 闲聊破冰 | What do you usually do on weekends? | small_talk | A2 |
| 经历分享 | Tell me about a trip you enjoyed. | travel | A2 |
| 偏好选择 | Do you prefer coffee or tea? Why? | daily | A2 |
| 情景应答 | You're at a café. The barista asks for your order. What do you say? | restaurant | A2 |
| 跟读练习 | Read aloud: [今日推送句子] | push_review | A2 |
| 简单描述 | Describe your favorite food. | food | B1 |

**MVP 不包含：** 辩论题、学术观点、商务汇报、雅思 Part 2 长篇独白

#### 5.2.4 问题生成规则

**MVP：** 从预置题库随机抽取 + 用户已收藏/推送句子的变体题

**V2：** LLM 按用户水平、历史弱项、话题动态生成

生成参数：

| 参数 | 选项（日常口语默认） |
|------|----------------------|
| difficulty | A2 / B1（MVP 不做 B2+） |
| scene | small_talk / travel / restaurant / shopping / daily / custom |
| time_limit_sec | 30 / 60 / 90（默认 60） |
| show_sample_answer | true（MVP 建议默认展示参考回答） |

#### 5.2.5 录音流程

```
点击「开始练习」
    → 展示题目 + 准备倒计时（3 秒）
    → 开始录音（显示计时）
    → 用户点击「完成」或到达时限自动停止
    → 保存录音 → 可选 ASR 转写
    → 回放 / 重录 / 下一题
    → 记录到练习历史
```

#### 5.2.6 录音数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| question_id | string | 关联题目 |
| user_id | string | 用户 |
| audio_url | string | 录音文件地址 |
| duration_sec | number | 时长 |
| transcript | string | ASR 文本（可选） |
| created_at | datetime | 创建时间 |

#### 5.2.7 验收标准

- [ ] 随机一题响应时间 < 1s
- [ ] 录音可正常开始、停止、回放
- [ ] 支持重录并覆盖
- [ ] 弱网环境下录音本地暂存，恢复网络后上传
- [ ] 用户可查看最近 30 条练习记录

### 5.3 模块三：每日推送 + 内容整理（Daily Push & Inbox）

#### 5.3.1 功能描述

每日向用户推送 **生活场景中的地道口语表达**（非新闻、非考试词汇）；用户可收藏、忽略，或整理进背诵材料（卡片/口语题）。

**推送内容标准：** 每条推送 = 1 个可直接说出口的表达 + 中文意思 + 场景说明 + 可选对话示例。

#### 5.3.2 用户故事

| ID | 用户故事 | 优先级 |
|----|----------|--------|
| P-01 | 作为用户，我想每天收到若干条推送内容 | P0 |
| P-02 | 作为用户，我想对推送「加入背诵 / 收藏 / 忽略」 | P0 |
| P-03 | 作为用户，我想在 Inbox 里统一查看待整理内容 | P0 |
| P-04 | 作为用户，我想从一条推送一键生成单词卡+例句卡 | P1 |
| P-05 | 作为用户，我想从推送生成一道口语练习题 | P1 |
| P-06 | 作为用户，我想设置推送时间（如早 8 点） | P1 |
| P-07 | 作为用户，我想按话题订阅推送类型 | P2 |

#### 5.3.3 推送内容结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| content_type | enum | 是 | phrase / sentence / mini_dialogue |
| scene | string | 是 | 场景（travel / restaurant / small_talk 等） |
| english | string | 是 | 英文表达 |
| chinese | string | 是 | 中文释义 |
| explanation | string | 否 | 用法讲解（为什么地道、和书面语区别） |
| dialogue | string | 否 | 迷你对话示例（2–4 轮） |
| difficulty | enum | 是 | A2 / B1 |
| audio_url | string | 否 | 母语者朗读 |
| push_date | date | 是 | 推送日期 |

**推送示例：**

| 场景 | 英文 | 中文 | 讲解 |
|------|------|------|------|
| 餐厅 | Can I get this to go? | 我可以打包吗？ | 比 Can I take this away? 在北美更口语 |
| 旅行 | Is it within walking distance? | 走路能到吗？ | 问路/看地图时高频 |
| 闲聊 | I'm beat. | 我累坏了。 | 比 I'm very tired 更口语化 |

#### 5.3.4 整理工作流

```
每日推送列表
    ├─ [加入背诵] → Inbox（待整理）
    ├─ [收藏]     → 收藏夹（仅浏览，不进复习）
    └─ [忽略]     → 不再展示

Inbox 整理页
    ├─ 生成记忆卡片（选牌组、拆卡规则）
    ├─ 生成口语题
    └─ 标记「已整理」→ 移出 Inbox
```

#### 5.3.5 推送来源（MVP）

| 来源 | 说明 |
|------|------|
| 运营预置内容库 | 初期主要内容来源 |
| 用户收藏句子的复习提醒 | 辅助推送 |

**V2：** RSS/新闻 API、AI 生成、社区UGC

#### 5.3.6 验收标准

- [ ] 用户每日可见固定数量推送（默认 5 条）
- [ ] 「加入背诵」后内容出现在 Inbox
- [ ] 从 Inbox 可成功生成卡片并进入牌组
- [ ] 已忽略内容不再出现在当日列表
- [ ] 推送通知可配置开关与时间

## 7. 核心用户流程

### 7.1 新用户首日流程

```
注册登录
  → 选择日常口语场景兴趣（旅行 / 餐厅 / 闲聊 / 购物，可多选）
  → 选择当前水平（A2 / B1）
  → 引导完成 1 次卡片复习（预置 10 张日常口语体验卡）
  → 引导完成 1 次情景口语录音（如：在咖啡店点单）
  → 展示今日推送
  → 引导将 1 条推送加入 Inbox 并生成卡片
  → 进入首页
```

### 7.2 老用户每日流程

```
打开 App（推送通知）
  → 首页查看今日任务
  → 完成卡片复习
  → 完成 1–3 道口语题
  → 浏览推送，整理 Inbox
  → 查看统计/打卡
```

## 8. 非功能需求

### 8.1 性能

| 指标 | 要求 |
|------|------|
| 首屏加载 | < 2s（4G 网络） |
| 卡片切换 | < 200ms |
| 录音启动延迟 | < 500ms |
| API P95 响应 | < 800ms |

### 8.2 可用性

- 支持 iOS 15+、Android 10+（若以 App 为主）
- 或 Web 响应式（若以 Web MVP 为主）
- 核心学习流程可离线：卡片复习、录音本地保存
- 无障碍：字体大小可调、按钮触控区域 ≥ 44pt

### 8.3 安全与隐私

- 录音默认私有，不上传至公开展示
- 传输 HTTPS；录音存储加密
- 提供隐私政策：数据用途、保留期限、删除方式
- 用户可删除全部录音与学习记录
- 符合 GDPR/个人信息保护法基本要求（若面向国内需做本地化合规）

### 8.4 可靠性

- 服务可用性 ≥ 99.5%
- 录音上传失败自动重试 3 次
- 每日备份用户学习进度

## 10. MVP 范围与版本规划

### 10.1 MVP（v1.0）— 日常口语最小可用版

| 模块 | 功能 |
|------|------|
