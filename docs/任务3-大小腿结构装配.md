# 任务3 大小腿结构装配

【任务描述】

本任务在足端单元预装合格的基础上，完成腿部中段与近端的分段装配与总成整合。学员按“分段装配、逐级校验”实施，掌握基准传递、承力件变形、定位几何、多自由度与镜像件防错、整链联动检验，形成可转入转动测试的腿部主体结构。基准清洁、轴心垂直、分步紧固与线束余量沿用任务2，本任务不再重复讲授。

【任务目标】

知识点

串联运动链分段装配的基准传递与误差叠加

承力件变形对孔系精度的影响及不得以紧固纠正的原因

同轴、偏心、偏移的含义及对接判定原则

多自由度关节分工与镜像件不可互换的原因

单段合格与整链联动检验的区别

技能点

能检查大、小腿连杆无弯曲、扭曲变形，确认安装端面可作为下一段装配基准

能将小腿支撑板定位孔与踝关节定位孔对齐并固定，做到无明显偏心、偏移

能将膝关节电机模组安装至小腿上端基座并对接大腿支撑板，形成中段主体结构

能以膝关节为基准校准腿部垂直度，区分左右 Roll 件，完成髋关节前摆电机与侧摆电机装配

能手动完成腿部伸直、折叠、抬腿、摆动，判定整链运动顺畅、无碰撞卡顿

素养目标

自下而上分段装配、逐级校验，不跳步、不颠倒顺序

左右件按标识安装，杜绝 Roll 连接件混装

不以拧紧纠正连杆变形，联动预检不通过不转序

【任务设施】

灵龙机器人小腿支撑板、足部总成、电机、大腿支撑板（左右）、大腿 Roll 关节连接件、螺柱 M3×8、螺柱 M4×12、配套内六角螺栓、检测工具等

【参考学时】

参考学时：6个学时

【知识储备】

分段装配与基准传递

1.1 基准传递

串联结构只能按已合格单元向上延伸。每一段的输出面是下一段的输入基准。跳步或颠倒顺序，会把前序误差叠加到后序孔位和轴心上。分段装配的要点是“一段合格，再接下一段”，而不是一次堆齐再总拧。

1.2 承力件与基准面

连杆类承力件的安装端面和孔系是几何基准，不是可随意拉形的弹性件。端面或孔系失准则后续执行器轴线必然歪斜。配合面清洁方法见任务2；本任务要建立的是“先承认基准、再决定能否装配”。

1.3 变形不得靠紧固纠正

弯曲使棱线不平、端面不能同时贴合；扭曲使两端相对扭转、对角孔高低不一。两类变形都会破坏同轴和对接。明显变形的承力件不得进入装配，不能靠加大预紧“扳直”，否则内应力锁进结构，运动中出现别劲、松退。

定位几何

2.1 同轴、偏心与偏移

两件对接时，定位孔应重合，紧固件能垂直自由穿入。轴线平行但错位称为偏心，孔系整体错档称为偏移。对位看孔与缝是否一致，不能凭外形“看起来差不多”。前段不同轴，误差会沿运动链向后传递。

2.2 段间对接

后段对接必须保护前段已经校准的轴线。紧固应分次、按序，避免单边先锁死把已校基准拉斜。对接口有偏移应松开重对，不得在错位状态下继续加力。轴心垂直与对角分次紧固的操作原则见任务2。

多自由度与镜像件

3.1 同一部位的多个自由度

一个部位若存在两个以上独立转动方向，通常由不同执行器、不同安装位实现，接口方向不能互换。装配前先分清各自由度对应哪一个接口，再决定执行器落点。

3.2 以已装关节为姿态基准

后段装配前，须把结构姿态校准到设计中立。已装关节可作为机械参照，用来恢复整体垂直或对中。姿态基准漂了，后装轴线会把倾侧带入整链。

3.3 镜像件不可互换

左右对称结构中的连接件往往互为镜像：安装面、孔向、走线口相反。能拧上不等于装对。装反会导致运动方向接反、结构干涉或整机偏斜。上机前按标识核对左右，不能靠试装判断。

3.4 接口件与执行器的叠装

先装机械接口件、再装执行器。接口件装斜，后装轴线随之倾斜；在歪斜接口上紧固，只会把偏心锁死。叠装链上每一级都要求无明显偏心、偏移。

整链检验

4.1 单段合格与整链合格

线束余量与避死角见任务2。本任务新增的是：单段对位合格，不等于整链在各主要自由度上都能走通。联动预检在断电下手动进行，应覆盖伸展、折叠和侧向等组合运动，用来暴露段与段之间的顶死、碰擦和别劲。无碰撞卡顿，才算主体结构装配合格。

4.2 转序条件

转入通电测试前，应同时满足：承力件无变形；各段同轴、无明显偏心偏移；镜像件左右正确；整链手动运动顺畅。任务2已判定的清洁、垂直和线束余量，本任务只复核是否被后续装配破坏。不满足则不具备转序条件。

【任务实施】

所需物料如下：小腿支撑板、足部总成、电机、大腿支撑板（左右）、大腿Roll关节连接件、螺柱M3*8、螺柱M4*12；配套内六角螺栓、检测工具。

本任务对应工艺流程“大小腿结构及膝关节分段装配、腿部总成整合”工序，自下而上分段装配、逐级校验，具体实施环节如下：

1. 大小腿构件预处理环节：清理大、小腿连杆上下安装端面及膝关节安装孔位，检查连杆无弯曲、扭曲变形，保证所有装配基准面平整、干净、无杂质。

2. 小腿模组装配定位环节：将小腿支撑板放置到踝关节定位处，尽量保证小腿支撑板定位孔与踝关节定位孔保持一致，完成固定，无明显偏心、偏移。

3. 膝关节装配定位环节：

① 机模组安装

将膝关节电机模组安装至小腿上端基座，校准旋转轴心，使轴心尽量与连杆保持垂直，完成定位并紧固，确保无明显偏心、偏移。

② 走线要求

线缆沿小腿支撑板凹槽向足后部引出，避免行走时与小腿部件发生干涉。

③ 段结构对接

膝关节紧固完成后，对接大腿支撑板与膝关节总成，按顺序逐级锁紧连接螺栓，形成腿部中段主体结构。

4. 髋关节电机装配定位：

髋关节共有髋关节前摆电机、髋关节侧摆电机两个电机需要装配。

① 腿部姿态校准与对接基准

以膝关节电机为基准，调整腿部整体垂直度；将大腿支撑板下方安装面与前序总成安装位对齐，确认无明显偏移后，用螺栓固定。

② 髋关节前摆电机装配

将前摆电机置于大腿支撑板上方安装位，用螺栓紧固，完成前摆电机装配。

Roll 关节连接件与侧摆电机装配：将大腿 Roll 关节连接件与髋关节安装位对齐后用螺栓紧固；注意区分左右件，不可混装。

再将髋关节侧摆电机安装于该连接件上，紧固时尽量保证无明显偏心、偏移。

③ 走线要求

全程注意线缆走向，避免与周边组件干涉。

5. 结构联动预检环节：手动完成腿部伸直、折叠、抬腿、摆动等动作，检查大小腿运动顺畅、无结构干涉、无碰撞卡顿，确保主体结构装配合格。
