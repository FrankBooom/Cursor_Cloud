# 任务2 脚部支撑件与踝关节电机装配

【任务描述】

本任务在任务1零件清点与检验合格的基础上，完成脚部支撑件与踝关节电机的末端单元预装。学员按照工艺原则“清洁对位、分步紧固、先装后检”，依次完成基准面清洁、电机核对与标定、对位装配、分级紧固、左右腿差异走线及全行程自检，形成可转入大小腿结构装配的合格足端单元。

【任务目标】

知识点

安装基准面清洁、平整贴合对轴心垂直与孔位对齐的影响

电机型号核对、标定要求及装配顺序不可改变的原因

对角交叉分次紧固原理及过紧变形、过松间隙的危害

末端动力线与信号线布置、行程余量及左右腿走线差异

踝关节俯仰、侧摆全行程自检项目与合格判定

技能点

能对脚部支撑底板、防滑减震垫、踝关节旋转垫片进行全面清洁，去除铝屑、油污、毛刺，确认基准面平整贴合

能核对电机型号，使用电机标定工具完成装配前标定，并遵守电机装配顺序

能将踝关节电机对准脚部支撑底板安装位，放置踝关节旋转垫片，保证轴心垂直、孔位对齐

能采用对角交叉分次紧固方式固定电机螺栓，均匀控制紧固扭矩

能规整踝关节电机动力线与信号线，按关节摆动行程预留运动余量，区分左右腿完成末端走线固定

能手动摆动踝关节，测试俯仰、侧摆全行程运动，判定无结构干涉、无卡顿、无异响

素养目标

遵守清洁对位纪律，不带屑、带油进入装配

严格执行电机标定与装配顺序，不擅自调换

区分左右腿线束，杜绝混装错接

先自检后放行，对干涉、卡顿、异响不隐瞒、不转序

【任务设施】

灵龙机器人脚部支撑底板、防滑减震垫、踝关节旋转垫片、电机、腿部连接线、螺柱、配套内六角螺栓、电机标定工具等

【参考学时】

参考学时：4个学时

【知识储备】

机械装配基准与清洁

1.1 配合面与装配基准

精密装配的精度首先取决于配合面。安装基准面的平面度、清洁度和贴合状态，决定轴心能否垂直、孔位能否自然对齐。基准不良时，后续紧固只会把倾斜和间隙锁死，不能靠加大扭矩纠正。凡构成同一配合链的表面，任一不合格，整组对位失效。

1.2 铝屑、油污、毛刺对装配的影响

金属切削残留以三种方式破坏装配：铝屑相当于局部垫高，造成单边倾斜；油污降低贴合摩擦，预紧后仍可能微移；毛刺阻碍贴合，脱落后进入转动副会引起卡滞或异响。清洁对象是所有进入配合链的表面，合格标准是无颗粒、无油膜、不划手、扣合无翘起。

1.3 清洁与对位的关系

对位是几何问题，清洁是对位成立的前提。带屑、带油时无法判断是否真正贴合，强行对孔会把杂质压入配合面。因此清洁必须在对位之前完成，而不是装配结束后补做。

关节电机安装与标定

2.1 型号、接口与力矩

关节电机的型号对应机械接口、孔距、输出力矩和线束接头。型号不符会出现装不上、力矩不足或过载。装配前核对型号，是把电机的电气身份与机械位置对应起来，防止错轴流入后续工序。

2.2 标定与零位

标定的作用是把电机电气零位对准机械基准。未标定就锁入结构，后续零位复核缺少参照；法兰一旦紧固，补标通常要拆解。因此标定必须在结构锁死之前，使用配套工具完成。未标定视为不具备装配条件。

2.3 多关节装配顺序

多轴机器人的电机按轴序、接口方向和出线口安装，顺序构成整机运动学与布线约束。顺序或左右一旦装错，不能在后续工序局部修改，只能拆解重装，并可能损伤螺纹与垫片。这是不可逆约束，须在对位前确认。

2.4 同轴、垂直与旋转垫片

回转件安装的基本几何要求是：轴线相对安装面垂直，连接孔同轴对齐。不垂直会产生偏载和摆动干涉；错孔强拧会拉伤螺纹并锁入倾斜。旋转垫片用于保证转动面的间隙与对中，缺失、装反或变形会导致卡滞、异响或轴向窜动。螺栓应能垂直自由穿入、四周缝隙均匀，才允许进入紧固。

螺纹紧固与运动线束

3.1 多螺栓均布紧固

均布螺栓的法兰若单边先拧死，板件会翻边，对角孔偏移，垫片局部压溃。对角交叉、分次加力，是为了让预紧沿圆周均匀建立。分步紧固解决的是受力均匀问题，不是简单“多拧几遍”。

3.2 预紧过紧与过松

过紧导致薄壁件或垫片变形、滑丝、轴心被拉斜；过松导致配合面有间隙，运动中松动、异响、退扣。合格预紧落在贴合无缝与零件不变形之间。紧固后应检查一周缝隙、垫片状态和螺栓头部高度是否一致。歪斜状态下继续加力只会放大误差。

3.3 动力线与信号线

关节电机同时存在动力回路与反馈/通信回路。动力线传输驱动电流，信号线传输编码器或总线信号。两类线应分开规整，避免缠绕挤压；接头键位必须匹配。布置阶段保持断电，线标错误会在通电后表现为错轴或通信失败。

3.4 运动余量与挤压死角

有相对运动的关节，线束必须按极限位置预留弯曲余量。静态整齐不等于运动合格：摆到行程两端仍应松弛、不拔接头，并避开锐边、螺栓头和转动剪切口。极限位拉扯是线束失效的主要原因，走线是否合格要用运动来验证。

3.5 双足结构的左右线束差异

双足机器人左右结构镜像，线束却常常不对称。本任务中左腿有接入头部的线路，右腿无。走线前先辨左右，再核对接头与支线数量。混装的结果是多余线无法固定，或头部通道缺失，后续整机无法正确插接。

装配检验与安全

4.1 全行程、全自由度检验

单元装配后的检验对象是该关节的全部自由度及其全行程，而不是中位手感。踝关节一般包含俯仰与侧摆。漏测一个方向，就可能漏掉该极限上的干涉或线束绷紧。检验应在紧固和走线都完成后进行，使检验状态与交付状态一致。

4.2 干涉、卡顿、异响

干涉指运动件相碰；卡顿指阻力在某角度突变或咬死；异响指刮擦、撞击或间隙碰撞。三者都是装配缺陷的外在表现，任一出现即不合格，须回到基准、对位、预紧或走线查找原因。合格表现为全程阻力均匀、无碰擦、无突变。

4.3 断电手动检验

结构未确认前不得通电点动。手动匀速摆动用于暴露机械干涉和线束拉扯，不用于检查控制参数。操作时避开剪切口与夹缝，遇卡死不得猛扳。

4.4 转序条件

转入下一工序前，装配单元应同时满足：配合面清洁贴合；电机身份与标定正确；几何对位与预紧均匀；线束左右正确且有运动余量；全行程无干涉、无卡顿、无异响。不满足则不具备进入后续结构装配的条件。

【任务实施】

所需物料如下：螺柱、脚部支撑底板、踝关节旋转垫片、电机、腿部连接线；配套内六角螺栓、电机标定工具等。

本任务对应工艺流程“末端单元预装装配”工序，采用清洁对位、分步紧固、先装后检的实施方式，具体实施环节如下：

1. 零件清洁预处理环节：对脚部支撑底板、防滑减震垫、踝关节旋转垫片进行全面清洁，去除铝屑、油污、毛刺，保持安装基准面平整贴合。

2. 踝关节电机对位装配环节：在开始装配之前需核对电机型号、对电机进行标定，因为机器人不可改变电机装配顺序。将踝关节电机对准脚部支撑底板安装位，然后再将踝关节旋转垫片放置在安装位，尽量要保证轴心垂直、孔位对齐。

3. 分级紧固锁止环节：采用对角交叉分次紧固方式固定电机螺栓，均匀控制紧固扭矩，避免过紧变形、过松产生间隙。

4. 末端线束布置环节：规整踝关节电机动力线与信号线，按照关节摆动行程预留运动余量，规避拉扯、挤压死角，完成末端走线固定。需注意区分左右腿线路，左右差异点在左腿有接入头部的线路，右腿无。

5. 单元装配自检环节：手动摆动踝关节，测试俯仰、侧摆全行程运动，确认无结构干涉、无卡顿、无异响，末端单元装配合格。
